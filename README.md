# Sonora — Aplicación web de música (Frontend con Blade y Tailwind CSS v4)

Interfaz web construida en Laravel 13 y Tailwind CSS v4 siguiendo estrictamente el sistema de diseño **Sonora**: paleta por capas de superficie (`surface-base`, `surface-raised`, `surface-high`), acento único ámbar (`accent` con texto `on-accent`), tipografías **Manrope** y **JetBrains Mono**, accesibilidad completa por teclado y reproducción simulada en tiempo real.

## Requisitos previos

- PHP 8.2 o superior (Laravel Herd o entorno local equivalente)
- Composer
- Node.js 18+ y npm

## Cómo ejecutar el proyecto

1. Clonar el repositorio y entrar a la carpeta del proyecto:
    ```bash
    git clone <url-de-tu-repositorio>
    cd sonora_sistema
    ```
